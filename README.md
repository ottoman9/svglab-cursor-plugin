# SVG Lab for Cursor

Let Cursor design inside [SVG Lab](https://svglab.app). Ask for app screens,
landing pages, icons, illustrations or charts, and SVG Lab's Design Engine
builds them as real, editable vectors with proper layout, spacing, type and
colour. Every design saves to your SVG Lab project, where you can watch it
live, edit it, and export SVG, PNG, PDF or code.

## Setup

1. Install the plugin from the Cursor Marketplace.
2. The first time Cursor calls SVG Lab, sign in to your SVG Lab account
   (Google or an email link). No API key is needed.
3. Ask: "Design a login screen for a coffee ordering app."

Every SVG Lab account gets 100 free credits (up to 24 app screens) once.
Plans and top-ups: https://svglab.app/billing

The plugin connects to the hosted SVG Lab MCP server at
`https://svglab.app/mcp` (streamable HTTP, OAuth 2.1). The first design call
can take 10 to 30 seconds while the Design Engine starts.

More: https://svglab.app/mcp-server · Setup for other apps: https://svglab.app/mcp-setup
